about=PostGIS Manager is a hybrid QGIS plugin and standalone application for managing PostGIS spatial databases.

    Features:
    • Multi-connection profiles (standalone, Docker, Podman containers)
    • Layer browser with schema/table/raster/view tree
    • Attribute table editor with SQL filter builder
    • SQL Editor with syntax highlighting, history and templates
    • Visual Query Builder (no SQL required)
    • Vector and raster import (GeoPackage, Shapefile, GeoJSON, GeoTIFF)
    • GeoPackage / Shapefile / GeoJSON export
    • PostGIS Topology editor
    • pgRouting (Dijkstra, A*, Driving Distance/Isochrones)
    • Linear referencing and chainage generation
    • DB Style Manager (save/load/delete QGIS styles in PostGIS)
    • Row-level versioning with pgVersion
    • Geometry validation and ST_MakeValid repair
    • Server-side geoprocessing (Buffer, Simplify, Convex Hull, Centroid)
    • 3DCityDB integration (detect schema, feature counts, SQL templates)
    • DB Dashboard (table sizes, cache hit ratio, connection stats)
    • Local network scanner for PostgreSQL/PostGIS instances
    • Docker/Podman container management and auto-connection
    • Config import/export
    • Georgian (ქართული) and English UI with runtime language switching
    • Light and Dark themes

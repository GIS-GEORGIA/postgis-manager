about=PostGIS Manager is a hybrid QGIS 4 plugin and standalone desktop app that fills the gap QGIS leaves in spatial database management — the "PostGIS as a GIS workspace" middle ground that neither QGIS nor pgAdmin covers well. Fully bilingual: English and Georgian (ქართული) with runtime switching. Light and Dark themes. Sidebar navigation (pgAdmin/DBeaver style).

    UNIQUE GIS TOOLS
    ────────────────
    • Map Viewer + Geometry Editor — render PostGIS layers and draw geometry directly into the table
    • CRS Browser & Reproject — search spatial_ref_sys, reproject a whole layer in place
    • CRS Audit — declared vs. actual SRID mismatch detection with one-click UpdateGeometrySRID
    • Spatial Join GUI — 7 predicates + KNN nearest, no SQL required
    • Spatial Data Quality Dashboard — 7 checks, 0–100 score, auto-fix (ST_MakeValid, dedup)
    • pgRouting Network Wizard — inspect → build topology → drive-time isochrones, no SQL
    • WFS Connector — OGC WFS 2.0 with CQL filters, streamed onto the map
    • GPX / KML Importer — field GPS tracks/waypoints/routes → PostGIS with Z + timestamps
    • Thematic Style Generator — Natural Breaks (Jenks), Quantile, Equal Interval
    • Layer Snapshot + Change Diff — spatial diff between timestamped snapshots

    PRODUCTION DATABASE TOOLS
    ─────────────────────────
    • SQL Editor (Show-on-Map), Query Builder, Attribute Table with inline editing
    • Vector/Raster Import, Export, Backup/Restore
    • pgRouting, Topology, Chainage, Geoprocessing, Validation
    • Table Designer, Schema/Role Manager, Function Browser, Materialized Views
    • Raster Tools, Style Manager, Versioning, 3DCityDB
    • Publishing (pg_featureserv/pg_tileserv), QGIS Bridge, Security/Audit
    • Docker/Podman instances, LAN scan, live DB dashboard

    QGIS PROCESSING PROVIDER
    ────────────────────────
    Adds algorithms to the QGIS Processing Toolbox: Import Vector, Export Layer,
    Validate Geometry, Geoprocess, Fix Invalid Geometry, Network Scan

    REQUIREMENTS
    ────────────
    psycopg2-binary (pip install psycopg2-binary)
    For raster import: raster2pgsql in PATH (PostGIS client tools)

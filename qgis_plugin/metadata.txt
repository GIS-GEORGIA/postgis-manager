about=PostGIS Manager is a hybrid QGIS 4 plugin and standalone desktop application for managing PostGIS spatial databases. All 21 panels are accessible from a clean sidebar navigation (pgAdmin/DBeaver style). Fully bilingual: English and Georgian (ქართული) with runtime switching. Light and Dark themes.

    PANELS & FEATURES
    ─────────────────
    • SQL Editor — syntax highlighting, persistent history, templates, CSV export
    • Query Builder — visual filter builder, no SQL required
    • Vector Import — Shapefile, GeoJSON, GeoPackage, KML; auto-CRS, append/replace
    • Raster Import — raster2pgsql wrapper with tile, SRID, overview options
    • Export — GeoPackage, Shapefile, GeoJSON, CSV with target SRID reprojection
    • Backup / Restore — pg_dump / pg_restore / psql GUI with live progress log
    • pgRouting — Dijkstra shortest path, Driving Distance, Isochrone
    • Topology — create, validate and browse PostGIS topology errors
    • Chainage — linear referencing, point-along-line, M-value assignment
    • Geoprocessing — server-side Buffer, Simplify, Convex Hull, Centroid, Union
    • Validation — invalid, null, duplicate, self-intersecting, wrong SRID
    • Table Designer — create/alter tables, column types, constraints, indexes
    • Schema / Role Manager — schemas, roles, GRANT/REVOKE GUI
    • Function Browser — browse, view source, execute DB functions
    • Materialized Views — create, REFRESH CONCURRENTLY, drop, preview
    • Raster Tools — statistics, histogram, map algebra (NDVI/threshold/custom), reproject
    • Style Manager — save/load QML styles to layer_styles table (QGIS-compatible)
    • Versioning — pgVersion row-level commit, checkout, diff, branch
    • 3DCityDB — auto-detect schema, feature counts by category, 6 SQL templates
    • Instances — Docker/Podman PostGIS container launcher and manager
    • Network Scan — LAN subnet scanner for PostgreSQL/PostGIS discovery
    • DB Dashboard — live pg_stat_* metrics: connections, cache hit, active queries

    QGIS PROCESSING PROVIDER
    ────────────────────────
    Adds 6 algorithms to QGIS Processing Toolbox:
    Import Vector, Export Layer, Validate Geometry, Geoprocess, Fix Invalid Geometry, Network Scan

    REQUIREMENTS
    ────────────
    psycopg2-binary (pip install psycopg2-binary)
    For raster import: raster2pgsql in PATH (PostGIS client tools)
